# OFF Communication — instruções para Claude

1. Extraia `OFF_Communication_MVP_Starter.zip`.
2. Abra a pasta `off_communication` no Claude Code (ou envie os arquivos ao Claude).
3. Abra `docs/CLAUDE_MASTER_PROMPT.md`.
4. Cole o conteúdo desse arquivo como instrução inicial.
5. Peça para executar somente a Fase A e aguardar sua aprovação antes da Fase B.

**Importante:** o prompt exige que o Claude teste o projeto e não declare como concluídas funções de áudio, Mesh ou background que ainda não foram implementadas/testadas.
